## 3. Main Protocol

### Shared label space

The five backbones use ANJS4 in order `[A, N, J, S]`.

- MELD: `anger -> A`, `neutral -> N`, `joy -> J`, `sadness -> S`.
  Other MELD labels remain dialogue context with target `-100` and do not
  contribute to supervised loss.
- IEMOCAP: `ang + fru -> A`, `neu -> N`, `hap + exc -> J`, `sad -> S`.
- eJSL and BOBSL already use `A/N/J/S`.

## 8. Method Abstraction Versus Engineering

The following is the implemented method abstraction:

1. Start from a trained source-only or joint visual emotion backbone.
2. Compute source emotion class centroids and an orthonormal low-rank emotion
   basis from their centered offsets.
3. Attach a zero-initialized residual adapter. Its residual is projected into
   the source emotion subspace; selected profiles may also use a small
   zero-initialized decision-space residual.
4. Train the adapter using labeled source and BOBSL examples while the anchor
   backbone is frozen. Loss components available in the implementation are
   source classification, BOBSL classification, source safety, source-logit
   stability, prototype alignment, residual magnitude, and optional
   distillation from a frozen peer checkpoint.
5. Save one deployable backbone-plus-adapter checkpoint. Peer checkpoints are
   training-only. Source and eJSL are evaluated with the same saved checkpoint.

The following are engineering choices and should not be promoted to separate
method claims:

- Per-backbone PKL parsing, tensor shapes, and checkpoint loaders.
- Different learning rates, class weighting, residual scales, distillation
  weights, and selected profiles for each backbone/corpus.
- Seed scheduling, GPU placement, tmux orchestration, resume checks, path
  naming, and batch-size reductions required by CMERC/ConxGNN.
- Large exploratory parameter sweeps and profile names.
- Choosing among source-only and joint anchors during development.

The final inference contract is one checkpoint. Historical routing, oracle,
and multi-checkpoint experiments listed below are not the final deployment
path.

The paper-level architecture, innovation framing, motivation-to-component
mapping, and abstraction rules are frozen in
`docs/SAST_METHOD_ABSTRACTION.md`.

## 12. Verification Checklist

Before using a result, verify:

1. The run has all five seeds `35 36 37 41 42`.
2. The BOBSL size is the intended one, normally B5K for the main table.
3. `selection_split` is source and `selection_metric` is weighted F1.
4. Source and eJSL summaries come from the same `model_best.pt`.
5. MMGCN paths include the extra `video/` result directory.
6. The report is not labeled oracle, routing, mixture, or held-out search.
7. Exact numbers are read from CSV/JSON, not rounded Markdown.
8. Generated artifacts are written under the `maokeyu` tree, never the
   read-only `wangyi` tree.
